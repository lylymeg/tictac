# ❌⭕ Tic-Tac-Toe Arcade (X-O)

Un jeu de **Morpion (Tic-Tac-Toe)** moderne, épuré et interactif développé en **Python** avec **Pygame**.

---

## 📸 Fonctionnalités

- 👥 **Mode 2 Joueurs Local :** Affronte un ami à tour de rôle sur le même écran.
- ✨ **Design Néon :** Interface élégante avec des symboles graphiques fluides (X vert et O rouge).
- 🔄 **Redémarrage instantané :** Touche `ESPACE` ou clic de souris pour relancer une partie après une victoire ou un match nul.

---

## 🚀 Lancement

```bash
pip install pygame
python main.py
